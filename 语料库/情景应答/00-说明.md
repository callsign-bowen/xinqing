# 情景应答语料库 v1

用途：给“情景聊天”的 AI 替身提供真实、圆滑、能说出口的回应参考。

## 文件

- `情景应答库-v1.jsonl`：第一批 49 条，覆盖 8 个场景
- `职场-提加薪-v1.jsonl`：最早的 8 条种子
- 后续按场景扩：催婚、冷暴力、借钱、甩锅、分手、拒绝加班

## 字段

```json
{
  "id": "raise-001",
  "scenario": "work-raise",
  "relation": "直属领导",
  "counterpart_line": "对方说的话",
  "intent": "对方在做什么",
  "strategy": "这一句用了什么接法",
  "response": "替用户说的话",
  "why": "为什么这样接",
  "source": "来源或提炼方式",
  "level": "A/B/C"
}
```

## 等级

- A：真实原话/字幕/访谈
- B：结构反推，接近真实说法
- C：策略样例，待真实语料替换

## 收录标准

1. 给对方留面子
2. 自己的意思说到了
3. 没把话说死
4. 没委屈自己
5. 用户能直接说出口

五条有一条不过，就不收。
