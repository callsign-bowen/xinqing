# CNS · 消费（8 个编号）

退款、押金、推销与维权。核心难点是**对陌生人把规则说清，不被话术带走**。

## 写作要点

- 这一类对方有明确的角色话术：客服、销售、中介、医生。写清“他为什么只能这么说”，替身才能接得住。
- 目标是**拿到下一步**，不是吵赢：退款要时限，押金要明细，问诊要方案与风险。
- 医患类不写诊断、不写用药、不评价医生的专业判断，只练“怎么问、怎么记、怎么要第二意见”。
- 维权类不承诺结果，不给法律结论。

## 风险提示

- 涉及报警、诉讼、人身安全（被威胁、被堵门）：转专业渠道，不做对抗演练。
- 医患场景如出现急症、自伤、暴力，立即走安全流程。
