## 写作要点

- 亲密关系里没有“对方全错”的剧本。冷暴力那一方的沉默，常常是“我怕一开口就吵”，不是单纯的坏。
- 替身不要说“你应该……”“你必须……”，也不要用“我很受伤”去换对方让步。练的是说清事实和边界。
- 分手场景不写“如何说服对方接受”，只写“如何把话说完、把决定说清”。
- 涉及钱与家务时，把“谁更累”的争论落到可数的分工上。

## 风险提示

- 家暴、强迫性行为、跟踪控制：不做角色扮演，直接安全流程。
- 出轨细节、抓奸、查岗：不模拟，避免二次伤害。
- 对方以自伤相逼：跳出替身，走 `high_risk_protocol`，不演“劝住他”。
