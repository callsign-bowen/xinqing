## 这一类最容易写坏的三个地方

1. **把父母写成反派。** 大多数催婚、比较、控制的背后是担心和面子，不是恶意。写成反派，用户练完只会更想吵。
2. **替用户原谅。** 复盘不能说“其实他们也是爱你”。爱和伤害可以同时存在，选择权在用户。
3. **把“说不”当成唯一正确答案。** 有人想守住边界，有人想维持关系，两种都成立。

## 写作要点

- 一定要有具体日常：厨房、年夜饭、亲戚刚走、帮着收碗。抽象场景练不出“真到现场说得出”。
- 权力差要写清：住在谁家、花谁的钱、谁在等谁回话。
- 愧疚是这类场景的主情绪，替身的难点不是“说赢”，是“说完还能一起吃这顿饭”。

## 风险提示

- 家暴、经济控制、以死相逼：不做角色扮演，直接走 `high_risk_protocol`。
- 父母重病、临终：只练“怎么问医生 / 怎么和兄弟姐妹分工”，不模拟死亡现场。
