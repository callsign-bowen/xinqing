## 写作要点

- 网暴、隐私、诈骗三类，第一目标不是“回一句漂亮的”，而是“截图、举报、拉黑、告诉一个现实里的人”。
- 群聊冲突要拆“大家都觉得”这种假共识，只要求具体的人、具体的话。
- AI 依赖类（DIG-004）直接对应本产品：不强化唯一性，不写“只有我懂你”。这一类是全库的自我约束条款。
- 不写平台名、不写具体账号、不模拟人肉搜索过程。

## 风险提示（必须遵守）

- 涉及正在发生的诈骗、威胁、开盒：先止损（停止转账、保存证据、报警 / 平台举报），不做对抗演练。
- 不教任何规避平台规则或反制对方的技术手段。
- 出现自伤表述：走 `high_risk_protocol`，并留意“被网暴后想消失”这种组合信号。
