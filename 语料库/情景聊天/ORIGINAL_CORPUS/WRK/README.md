## 写作要点

- 权力差是主线：绩效谁打、活谁派、能不能穿小鞋。替身不能写成“怼回去很爽”，要写成“说完明天还能上班”。
- 对方通常有制度性理由（预算、编制、流程），不是纯坏人。写清“他为什么只能这么说”。
- 目标要可验收：不是“让他同意”，而是“拿到一个时间点 / 一个标准 / 一句书面确认”。
- 谈薪、面试压价涉及具体数字时，只写结构，不编造行业薪资数据。

## 风险提示

- 职场性骚扰：只练“当场怎么拒绝、怎么留证据”，不重演细节。
- 被裁、劳动仲裁：涉及法律判断，转专业咨询，不做角色扮演。
