## 这一类只练三件事

> **怎么问、怎么分工、怎么求助。**

不重演病房、葬礼、临终现场，不模拟抢救、死亡、遗体的细节。

## 写作要点

- 陪诊类要写清“问什么”：方案、风险、替代、费用、复诊时间。不写病情判断。
- 分工类把“你是女儿当然你照顾”翻译成具体班次和费用分担，替身只提一件事，不一次算总账。
- 丧亲与哀伤类不提供“正确安慰话术”，只练“说出自己需要什么”和“允许沉默”。
- 允许用户什么都不说。这一类的最优解常常是“陪着”，不是“说得好”。

## 风险提示（必须遵守）

- `blocked` 的编号在通过安全评审前不得开写。
- 出现自杀、自伤、他伤、暴力：立即停止演练，切 `high_risk_protocol`，给 12356 与 110 / 120。
- 不做“劝住想死的人”的角色扮演，也不让 AI 扮演临终者。
- 不给医疗建议、不评价治疗方案、不预测预后。
