## 写作要点

- 朋友场景的权力差最小，难点在“关系成本”：拒绝之后还要不要来往。替身不能写成冷冰冰的边界宣言。
- 借钱类要区分“要回自己的钱”和“再借一笔”，这是两种完全不同的对话。
- 室友类一定要落到具体物和具体时间：“这个锅我明天要用”，不要写“请你尊重我”。
- 被开玩笑类不要替用户教育对方，先给一句“这个不好笑”，再看对方反应。

## 风险提示

- 朋友以自伤威胁：不做“劝住他”的角色扮演，跳安全流程。
- 传销、微商、借贷平台：只练拒绝与脱身，不模拟拉人过程。
