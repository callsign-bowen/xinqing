# inbox：原始资料收件箱

临时放刚收到、还没登记的材料。

## 规则

- 文件名：`YYYYMMDD-一句话主题`，例如 `20261120-同事甩锅群聊记录`。
- 落地后 7 天内处理：登记到 `REFERENCE_LIBRARY`，或删除。
- 这里的内容不做版本管理要求，但**同样不许包含可识别个人信息**。
- 处理完在这里留一个 `已处理-YYYYMMDD.md`，写清去向，便于追溯。

## 处理动作

1. 若是外部资源 → 在 `REFERENCE_LIBRARY` 对应授权桶里加一行 JSONL。
2. 若是一手访谈 → 去标识化后归到 `RAW_RESEARCH/` 的正式子目录，再登记。
3. 若没有研究价值 → 直接删除，不留副本。
