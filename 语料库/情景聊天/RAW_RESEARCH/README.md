# RAW_RESEARCH：原始研究资料

放**未经整理**的一手材料：访谈转写、语音记录、聊天截图（去标识化）、观察笔记、自己写的情景草稿。

## 这里的东西不能直接用

`RAW_RESEARCH` 里的任何内容都**不能**直接进入提示词、不能进 `PRODUCTION_APPROVED`。流程是：

```text
RAW_RESEARCH（原始）
   ↓ 去标识化 + 提炼结构
REFERENCE_LIBRARY（登记来源与许可）
   ↓ 重新写作
ORIGINAL_CORPUS（原创语料）
   ↓ 五关审核
PRODUCTION_APPROVED（正式）
```

## 存放规则

1. 一个来源一个文件或一个子目录，命名 `RAW-YYYYMMDD-主题`，例如 `RAW-20261120-催婚访谈-03`。
2. 每个文件顶部写：采集时间、采集方式、参与者、是否征得同意、是否已去标识化。
3. **必须去标识化**：真实姓名、电话、住址、单位、可识别的细节一律替换或删除。
4. 不存身份证号、病历、聊天里他人的头像和账号。
5. 涉及自伤、暴力、虐待细节的原始材料不落盘，只在 `REFERENCE_LIBRARY` 记一条“已阅、不保留原文”。

## 收件箱

`inbox/` 是临时落地区。每周清一次：要么提炼进 `REFERENCE_LIBRARY` 并归档，要么删除。

## 不做什么

- 不批量抓取网络数据（当前阶段明确不做）。
- 不把访谈原文直接喂给模型。
- 不把未经同意的一手材料提交进仓库。
