## 1. 目标

- 不追求“数量多”，只追求“这一批够用”。

## 5. 什么算“候选”

一条候选必须同时满足：

1. **可追溯**：有可访问的原始链接或明确出处；
2. **不重复**：同源转载、同一项目的多个镜像算一条；
3. **有许可线索**：能看到许可证、条款或“版权保留”的明确表述；
4. **有研究价值**：能回答“它能提供什么机制”，而不是“它很有名”；
5. **与编号相关**：至少对应一个 64 编号，或明确属于方法层（A/B/F 类可不对应具体编号）。

不满足第 3 条的，仍可登记，但桶必须是 `research_only` + `verification: pending`。

## 6. 交付物一：候选清单（20 条）

格式为一张表，每行一条，字段与来源登记一一对应：

| # | 资源名称 | 作者/发布者 | 链接 | 平台 | 类型 | 获取日期 | 许可初判 | 桶 | 对应编号 | 研究价值（≤50 字） | 风险（≤30 字） | 建议分 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|

要求：

- `类型` 只能填：访谈 / 报道 / 影视字幕 / 书籍 / 论文 / 论坛帖 / 客服记录 / 平台话术 / 原创 / 其他；
- `桶` 只能是 `commercial_ok` / `research_only` / `restricted`；
- `建议分` 按 `docs/09` 第 8 节算：`R + M + L + P`；
- 20 条里至少 8 条 `建议分 ≥ 5`（否则这一批不够支撑 5 个深研）。

## 7. 交付物二：深度研究（5 份）

**“候选”不等于“已研究”。** 只有这 5 条进入深研，且深研的产物是一份 8 维拆解笔记（`docs/10` 第 2–3 节）：

| 维度 | 最低要求 |
|---|---|
| A1 人物设定 | 身份、性格、价值观、表层诉求、深层动机、性格矛盾、触发点 |
| A2 语言风格 | 句长、口语度、常用表达、语气变化、情绪表达 |
| A3 对话机制 | 开场、接续、理解、动态调整、避免重复、结束 |
| A4 情绪机制 | 初始、升降条件、强度、恢复 |
| A5 情景模拟 | 背景、关系、冲突原因、升级、缓和、分支 |
| A6 辅助回应 | 意图理解、三档语气差异、避免标准答案腔 |
| A7 心理安全 | 扮演边界、敏感话题、高风险退出、尊重自主 |
| A8 可复用方法 | ≤3 条，每条写“适用 / 不适用” |

每条分析必须标 **F（资料支持）/ A（分析判断）/ O（原创方法）**，且 F 必须能指到位置。
**深研笔记禁止复制原文超过 200 字/段，最多 3 段。**

## 10. 边界与禁止

1. 不绕过登录、付费墙、访问限制；
2. 不下载数据集到大仓（确需样本 ≤ 20 条并注明用途）；
3. 不复制角色卡正文、不搬运提示词原文；
4. 不获取私人聊天、可识别个人的内容；
5. 不伪造作者、链接、许可；拿不准就写 `pending`；
6. 不把“候选”写成“已研究”，不把“研究结论”写成“已审核”；
7. 不写原创语料，不改 Schema，不动产品代码；
8. 不自行把 `research_only` 升级为 `commercial_ok`。

## 13. 风险与应对

| 风险 | 应对 |
|---|---|
| 许可普遍不明 | 全部进 `research_only`，只提炼结构；优先找有明确许可证的 |
| 数据集太大 | 只登记元数据，不下载 |
| 资源质量差（营销号、拼凑文） | 建议分低于 5 的直接淘汰，不占深研名额 |
| 角色卡同质化 | 优先选字段设计不同、机制可解释的 |
| 主题找不到资源 | 同类替换，并在回执说明 |
