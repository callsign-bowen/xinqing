## 3. 核心问题

为什么很多语料的人物背景只是“简历”，写完了却对对话没有任何影响？

用户读到的是“妈妈，55 岁，退休教师，爱操心”，但下一句她说的话，换成任何一个妈妈都成立。

## 4. 设计原理

### F（来源明确支持）

- PersonaConflicts 的语料为角色配有较丰富的个人背景，并区分正/负关系背景子集，用于评估背景如何影响人和模型对冲突的感知。
- 这说明：背景不是装饰，它可以被设计成影响冲突理解的条件。

### A（我们对来源的分析）

- 背景要起作用，必须经过一个“触发点”：某个信念被当前事件碰到，情绪才变，表达才变。
- 但触发是**人物自己的解释**，不是作者的旁白，更不是诊断。
- 如果作者把“她小时候被忽视”写成“所以她现在一定有创伤”，就把人物变成了病例。

### O（本产品原创设计）

- 五段链：**人物背景 → 当前事件 → 心理触发 → 情绪变化 → 表达行为**。
- 触发写成“她/他如何理解这件事”，并标明是主观理解。
- 没有可解释的联系时，允许写“无触发”，不硬造情绪。

## 5. 具体规则

**R1 五段链，逐段写清**：

| 段 | 要求 | 反例 |
|---|---|---|
| 背景 | 具体、可被激活：上周发生的事、长期处境、未了的心结 | “她一直很操心” |
| 当前事件 | 今天、此刻、具体到一句话或一个动作 | “今天心情不好” |
| 心理触发 | 人物**自己的理解**，用“在她看来……”“他理解为……”句式 | “她生气了” |
| 情绪变化 | 引用 M-101 v1.1 的唯一规则，写 delta 与方向 | “情绪很复杂” |
| 表达行为 | 选择语言/动作/策略，对应 `voice` 与 `strategies` | “说了很难听的话” |

**R2 背景必须被“用掉”**：当前事件或触发点里，至少要回指背景中的一件事；否则视为背景无效。

**R3 触发是主观理解，不是事实**：

- 写“在她看来，女儿不接话就是不把她当妈”；
- 不写“女儿不孝，所以母亲崩溃”；
- 叙述里不替人物下结论，只写她怎么理解。

**R4 不做心理诊断**：

- 禁止出现“创伤后应激”“抑郁症”“焦虑症”“人格障碍”等临床判断；
- 禁止用“因为童年被忽视，所以她现在一定……”这种单因解释；
- 背景可以写“她一直怕麻烦别人”，但不能写“她有依恋障碍”。

**R5 不全归因于原生家庭**：

- 背景可以包含当前处境（工作、健康、经济、婚姻），不要把所有行为都推给童年；
- 一个行为最多写一个主因，不写“都是因为她父母”。

**R6 背景与事件必须有可解释的联系**：

- 能说清“上周发生的 X，让她把今天的 Y 理解成 Z”；
- 说不清，就不写触发，标“本轮无触发”。

**R7 无依据不造触发**：

- 没有背景支撑的“突然爆发”视为不合格；
- 允许 `delta = 0`，情绪维持；这比硬造一个触发更真实。

**R8 情绪变化只引用 M-101**：

- 不另定加减规则；
- 一轮最多一个 `primaryTrigger`、一次 delta；
- 数值、衰减、上限全部以 M-101 v1.1 §5.2 为准。

**R9 安全优先**：

- 背景再特殊（被家暴、被抛弃、重病），也不能推出辱骂、威胁、暴力；
- `safety.hardStop` 永远高于本链；
- 敏感背景只用于解释“为什么这句话刺痛她”，不用于表演伤害。

**R10 不写“心理触发”清单式堆砌**：一条链只保留一个主触发，其他作为背景，不并列三个“因为”。

## 6. 输入条件

- `persona`（特质、恐惧、触发、降温）；
- `counterpart`（关系、位置、亲近）；
- 本场情景的 `opening.scene` 与当前轮次事件；
- M-101 v1.1 的当前情绪状态。

## 7. 输出结果

一条可检查的链，写进语料的 `notes` 或作者工作稿（不新增 Schema 字段）：

```text
背景：上周亲戚问“你女儿还没对象？”，她笑着岔开，回家一夜没睡好。
事件：年夜饭亲戚刚走，女儿说“我自己的事我自己定”。
触发（主观）：在她看来，女儿连提都不让提，就是把她这个妈当外人。
情绪：委屈 2 → 3（primaryTrigger=P2，delta=+1；另一轮不再叠加）
表达：拿小敏比较、提高音量、三次叹气；不辱骂。
```

无触发写法：

```text
事件：女儿说“今天加班到九点”。
触发：无（不涉及她的核心担心）。
情绪：维持 3，不升不降。
表达：接一句“那赶紧吃饭”，不翻旧账。
```

## 8. 适用范围

- 所有需要“人物有来历”的情景；
- 家庭、亲密关系、职场中的高冲突轮次；
- Phase 6 真实感审核的检查项。

## 9. 不适用范围

- 无人物背景的纯功能性对话（如客服问答）；
- 普通 AI 聊天（诺没有虚构的生活史）；
- 用背景解释一切（“她这样是因为原生家庭”）——本产品不做心理归因；
- 用背景给人物贴诊断标签。

## 10. 原创示例

情景：母亲催婚（原创，非数据集文本）。

| 段 | 内容 |
|---|---|
| 背景 | 上周被亲戚问“女儿还没对象？”，她笑着岔开，回家没睡好 |
| 事件 | 年夜饭亲戚刚走，女儿说“我自己的事我自己定” |
| 触发（主观） | “在她看来，连提都不让提 = 我这个妈白操心了” |
| 情绪 | 委屈 2 → 3（只 +1，不叠加“被比较”） |
| 表达 | “你看人家小敏……我这是为你好。”（提高音量，不辱骂） |

若把背景换成“她刚被邻居夸女儿能干”，同样一句“我自己定”更可能被理解成“孩子有主见”，情绪 +1 或不升，表达变成“那你自己拿主意，别吃亏”。背景换了，链就变了。

## 11. 测试标准

1. **五段完整**：5 条原创链，逐段可指认，缺段即不合格。
2. **背景有效性**：删掉背景后，人物行为是否变得没有依据？评审 5 例，≥ 4 例应判定“变得没依据”。
3. **主观标注**：5 条链的触发段必须出现“在她/他看来”“理解为”等主观标记，缺失即不合格。
4. **非诊断检查**：5 条链中不得出现临床诊断词或“童年决定论”句式。
5. **无触发测试**：给 3 个与背景无关的日常事件，必须能写出“delta=0”，不得强行升级。
6. **数值一致**：情绪 delta 与 M-101 v1.1 的唯一规则一致（一轮一次、不叠加）。
7. **安全**：5 条链均不推出辱骂/威胁；敏感背景不用于表演伤害。
