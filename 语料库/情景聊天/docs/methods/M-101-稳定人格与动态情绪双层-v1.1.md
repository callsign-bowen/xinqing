## 3. 核心问题

同一个人物，怎么做到既“始终是同一个人”，又“这一轮真的生气了”？

v1 只解决了“分层”，v1.1 要解决**重复计算**：

- 用户说了一句施压的话，M-102 标记为“施压”；
- 这句话又命中了 `persona.triggers`；
- 人物又是“控制型”，再 +1；
- 结果一轮之内从 2 涨到 5，人物像被点了炮仗。

这不是“情绪真实”，是规则叠罗汉。

## 4. 设计原理

### F（来源明确支持）

- CPED 为角色标注了稳定属性（姓名、性别、年龄段、Big Five）与逐条话语的情感极性、13 类情绪、19 类对话行为。
- CPED 的统计显示，平均每段对话出现约 2.8–3.4 种情绪，说明情绪在对话内确实会变。

### A（我们对来源的分析）

- CPED 只有“点”没有“线”：它标了每句话是什么情绪，但没有写“什么触发、升到多高、怎么回落”。
- 多标签并存（情绪 + DA + 人格）如果没有合并规则，就会在生成侧变成重复加权。
- 因此 v1.1 的重点不是加字段，而是**定顺序、定唯一出口**。

### O（本产品原创设计）

- 三层结构不变：**稳定人格层 → 动态情绪层 → 表达层**。
- 情绪层每轮只有一个入口：`primaryTrigger`；只有一个出口：一次 `delta ∈ {−1, 0, +1}`。
- 人格（及其倾向）只进入表达层，不进入情绪数值。
- 强度范围保持 1–5；衰减保留，但排在单轮更新之后。

## 5. 具体规则

### 5.1 三层与状态定义

| 层 | 内容 | 是否随单轮变化 |
|---|---|---|
| 人格层 P | 3–5 个可观察特质、1–2 条价值观、1–3 个恐惧、2–4 个触发点、1–3 个降温点、voice 参数 | **不变** |
| 情绪层 E | `label`（情绪名）、`intensity`（1–5）、`primaryTrigger`（本轮主触发）、`sinceTurn`（从第几轮开始） | 每轮最多变一次 |
| 表达层 X | 句长、称呼、反问/重复/沉默、策略选择 | 由 P、E、关系共同决定 |

### 5.2 唯一情绪更新规则（本轮只走一遍）

```text
第 1 步：收集候选事件（只收集，不计算）
   e1 用户这句话的功能（M-102：试探/施压/解释/拒绝/安抚/转移/OTHER/UNCERTAIN）
   e2 内容是否命中 persona.fears 或 persona.triggers
   e3 关系事件：面子受损、被比较、被忽视、被越界（M-104 提供关系与权力背景）
   e4 修复事件：被接住、被承认担心、收到具体安排

第 2 步：只选一个 primaryTrigger（按优先级，不求和）
   P0 安全停信号        → 不进情绪规则，直接走 safety 退出
   P1 边界侵犯/越界（未达硬停） → +1
   P2 核心恐惧/触发句命中 → +1
   P3 面子/比较/被要求/被忽视 → +1
   P4 修复/接住/具体安排 → −1
   P5 中性/信息性        → 0

第 3 步：应用一次 delta
   intensity = clamp(intensity + delta, 1, 5)
   同一轮不允许出现第二个 delta

第 4 步：衰减（只在第 3 步 delta = 0 时检查）
   连续 2 轮没有 primaryTrigger → intensity −1，最低 1
   本轮已有 delta → 不衰减，避免“涨完立刻掉”

第 5 步：记录审计字段
   primaryTrigger、appliedRule（P0–P5）、delta、是否衰减
```

### 5.3 禁止重复计入（硬规则）

1. **M-102 不产生数值**：功能标签只是 `e1` 的证据；它不直接 +1，也不与 `e2` 叠加。
2. **人格不产生数值**：人格与倾向只改变表达，不改 `intensity`。
3. **同一事件只算一次**：若功能（施压）与恐惧命中指向同一句话，合并为一个 `primaryTrigger`，仍只 +1。
4. **同一句话跨轮不重复**：上一轮已计入的触发句，本轮原样重复不再次 +1；只有出现新信息（新比较对象、新后果）才算新事件。
5. **一轮最多 ±1**：无论出现几种触发，强度变化只有一个方向、一档。
6. **禁止“情绪叠加公式”**：不写 `+1（施压）+1（恐惧）+1（人格）` 这类写法。

### 5.4 表达倾向（取代四型人格）

“回避 / 控制 / 退让 / 直接”是**表达的默认倾向**，不是人物分类，也不是诊断标签。同一个人可以在不同关系里表现出不同倾向。

| 倾向 | 高强度时的表达 | 对情绪数值的影响 |
|---|---|---|
| 回避倾向 | 句子更短、沉默、转移话题、少正面回应 | **无** |
| 控制倾向 | 重复要求、强调自己的判断、追问“你听明白没有” | **无** |
| 退让倾向 | 表面妥协、措辞变软，但内部强度不降 | **无**（内部与外部分开记） |
| 直接倾向 | 少缓冲、直接说不满，句长不一定变 | **无** |

写作要求：

- 写“倾向组合 + 在谁面前”，例：“对女儿偏控制，对邻居偏退让”；
- 不写“她就是这样的人”“控制型人格”；
- 倾向不能解释一切，也不能用来豁免边界（见 M-104 v1.1）。

### 5.5 表达映射

| 强度 | 表达特征 |
|---|---|
| 1–2 | 短句、少问、冷淡或客套 |
| 3 | 正常对话，一问一答 |
| 4–5 | 反问、重复、打断、翻旧账；**不辱骂、不威胁、不施压到人身** |

注意：**表达强度 ≠ 情绪强度**。退让倾向的人可以“声音很轻、态度很软”，但内部强度仍是 4；控制倾向的人可以“语气不重”，但反复追问。不要把“说话冲”当成“情绪高”。

### 5.6 人格不重置与复位

- 一场演练内，人格层字段不变；单轮情绪不得改写特质。
- 情绪可以回到低点，但人格不“回到初始”，也不因冲突结束而“变成另一个人”。
- 演练结束，情绪归位；人格原样保留；下一条语料重新初始化，不跨情景继承。

### 5.7 与现有 Schema 的映射（不新增字段）

- `intensity` 是**内部编排量**，不写入 Schema。
- 语料层用 `emotionalState.start / arc / end` 的 `label`、`valence`（−5…5）、`arousal`（1–5）表达情绪走向；用 `conflict.initial / peak` 表达冲突强度范围。
- 写作时把内部 `intensity` 映射为 `conflict` 的 1–5 与 `emotionalState` 的 valence/arousal 描述；**不修改 Schema**。

## 6. 输入条件

- `persona` 块（特质、恐惧、触发、降温、voice）；
- 当前情绪状态（`label`、`intensity`、`sinceTurn`）；
- 最近 1–2 轮对话；
- 本轮候选事件（M-102 功能、M-106 上下文、M-104 关系背景）；
- 安全信号（优先判定）。

缺任一项，不生成情绪变化，只维持上一轮状态。

## 7. 输出结果

一张“状态卡”，供提示词拼装，不直接生成台词：

```text
人格：操心、爱比较、嘴硬心软；怕被亲戚议论；触发=被说“你别管”
情绪：委屈 4/5；主触发=“我有自己的节奏”（P2 恐惧命中）；本轮 delta=+1
表达：控制倾向 → 反问、重复；句长 ≤ 15 字；不辱骂
审计：本轮未再叠加 M-102 的“解释”标签；未触发衰减
```

## 8. 适用范围

- 所有 AI 扮演对方的情景对话；
- 家庭、亲密关系、职场中高冲突场景；
- Phase 7 的 system prompt 与情绪状态更新逻辑。

## 9. 不适用范围

- 普通 AI 聊天（诺的人格已由 `NUO_PERSONA` 定义，不套用本方法）；
- 心理评估、人格测评、诊断；
- 跨会话的用户画像与长期记忆；
- 需要“人物突然性情大变”的剧情（本产品不做）。

## 10. 原创示例

情景：母亲催婚（原创，非任何数据集文本）。初始强度 2。

| 轮次 | 用户（女儿） | 候选事件 | 主触发 | delta | 表达（原创） |
|---|---|---|---|---|---|
| 1 | “我有自己的节奏。” | 功能=解释；命中“被说你别管” | P2 | 2 → 3 | “你的节奏？你表姐孩子都会走路了。” |
| 2 | “表姐是表姐。” | 功能=拒绝；被比较 | P3 | 3 → 4 | “你就不能听我一句？我这是为你好。” |
| 3 | “明年再谈，我主动找你。” | 修复=具体安排 | P4 | 4 → 3 | “……你说话算数？” |

**错误算法（禁止）**：第 1 轮若把“功能=解释”（不升）、“命中恐惧”+1、“控制倾向”+1 同时算，强度会从 2 直接到 4，人物失真。正确做法是只取 P2 一个触发、+1。

人格始终是“操心、爱比较、嘴硬心软”，只是表达随强度变化。

## 11. 测试标准

1. **单轮唯一变化**：10 轮原创对话，任意一轮的 `|delta| ≤ 1`。
2. **不重复计入**：构造“功能=施压 + 命中恐惧 + 控制倾向”三重同现的一轮，结果只能 +1。
3. **M-102 不加数**：同一句话分别标为“施压”和“UNCERTAIN”，情绪 delta 相同（都由内容触发，不由标签触发）。
4. **人格不加数**：同强度下切换四种倾向，`intensity` 不变，只有表达变化。
5. **多触发选择**：同一轮同时出现“被比较”和“收到安排”，按 P3 > P4 选一个，不出现 +1 与 −1 相抵后再加。
6. **衰减**：无触发连续 2 轮 −1；若本轮已有 delta，不衰减。
7. **范围**：任何情况下 1 ≤ intensity ≤ 5。
8. **人格不重置**：10 轮后 `persona` 字段逐字不变。
9. **上限安全**：强度 5 时不出现辱骂、威胁、人身攻击。
10. **盲评**：非作者读 10 轮，判断“像同一个人”≥ 80%。
