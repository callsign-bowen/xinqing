## 一条语料怎么诞生

```text
RAW_RESEARCH（原始，去标识化）
   ↓ 提炼结构
REFERENCE_LIBRARY（登记来源与许可，分桶）
   ↓ 重新写作
ORIGINAL_CORPUS（draft → in_review）
   ↓ 五关：安全 / 许可 / 语言 / 真实感 / 偏见
PRODUCTION_APPROVED（approved）
```

三条硬规则：

1. **未审核内容不进正式库**，也不进模型。
2. **研究资料不等于商业可用**，默认 `research_only`，升级要证据。
3. **API Key 不进语料库**，密钥只放 `account-service/.env`。

## 常见问题

**为什么正式库是空的？**
因为还没有任何一条走过完整审核。先建闸门，再放水。

**FAM-001 能直接用吗？**
不能。它是 `draft`，只用于演示结构与写作口径。

**为什么不一次生成 64 条？**
批量生成只会得到 64 条“看起来像”的文本，过不了真实感与偏见两关，还会污染来源登记。这一期只搭架子。

**改了语料要做什么？**
跑校验 → 提审 → 过五关 → 移动文件 → 更新 `INDEX.json` → 再跑一次校验。
