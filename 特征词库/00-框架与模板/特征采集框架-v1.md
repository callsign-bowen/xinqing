# 特征采集框架 v1（通用）

日期：2026-11-13
用途：以后收集“温柔、直接、幽默、稳定、倾听、清醒、教练”等任何特征，都按这一套走
示例：温柔词库已经按这套跑通，见文末链接

---

## 0. 一句话

> **先定边界，再多源采样；先收原话和场景，再分级、归档、蒸馏；先跑 12 条，再扩到 100 条。**

---

## 1. 适用对象

这套框架不只用于“温柔”，也用于：

- 直接
- 幽默
- 稳定
- 倾听
- 清醒
- 教练
- 书卷气
- 松弛
- 有边界

换的只是“特征名”和“场景”，流程不变。

---

## 1.5 最低交付标准

每收完一个特征，至少要达到：

| 项目 | 最低 |
|---|---:|
| 原话 / 场景素材 | ≥ 50 条 |
| 蒸馏词库 | ≥ 50 条 |
| 场景 | ≥ 20 个 |
| 每条词库 | 2 个说法 + 反例 + 来源 |
| 高风险 | 单独成组，不混在普通场景里 |

如果原话不够 50 条：

- 可以用 C 级“场景句”补，但必须标注“C 级 / 提炼 / 非逐字原话”。
- 不能把 C 级说成原话。
- 验收页要写清楚 A/B/C 各多少。

---

## 2. 八步法

### 第一步：定义边界

写三张清单：

| 清单 | 要写什么 | 例子：温柔 |
|---|---|---|
| 是什么 | 3–5 条可观察的行为 | 接住、不侵入、有边界 |
| 不是什么 | 最容易混淆的 3–5 条 | 不是语气软、不是讨好、不是没立场 |
| 容易混淆 | 和哪些特征容易混 | 温柔 vs 顺从；温柔 vs 冷漠 |

边界不清，后面会收进来一堆“鸡汤”和“暧昧话”。

### 第二步：多源采样

至少覆盖 5 类来源：

1. 真人访谈
2. 咨询 / 教练案例
3. 影视
4. 动漫
5. 书摘
6. 网站 / 社区
7. 学术 / 播客

每一类补的东西不同：

| 来源 | 补什么 | 注意 |
|---|---|---|
| 真人访谈 | 分寸、语气 | 别把客套当性格 |
| 咨询/教练 | 怎么接住、怎么推进 | 有专业关系支撑，AI 不能照搬 |
| 影视 | 日常怎么说 | 有剧情加成，纯文字要更短 |
| 动漫 | 人物感、金句 | 不要自称角色 |
| 书摘 | 长期智慧 | 金句多，场景少 |
| 网站/社区 | 真实用户场景、原话 | 必须追溯原出处 |
| 学术/播客 | 方法有没有依据 | 别把研究结论说成话术 |

### 第三步：原话 + 场景 + 出处

每条素材必须有：

| 字段 | 说明 |
|---|---|
| 原话 | 尽量逐字；不是逐字就标“大意/转述/意译” |
| 谁说的 | 人名 / 角色 / 平台 / 作者 |
| 当时场景 | 对谁说的、发生了什么、前后文 |
| 原始链接 | 网站素材必须留 |
| 采集日期 | 防止内容被改 |
| 等级 | A / B / C |

没有场景的句子，不收。

### 第四步：质量分级

| 级别 | 是什么 | 怎么用 |
|---|---|---|
| A | 原话 / 字幕 / 访谈原句 / 论文原句 | 可参考语气，仍要改写 |
| B | 意译 / 转述 / 中译 / 文章概述 | 只用动作，不用原句 |
| C | 模板 / 提炼 / 大意 | 当规则，不当台词 |

### 第五步：按场景归档

不要按作品归档，按“用户现在是什么场景”归档。

通用场景池：

- 低落 / 哭
- 累 / 耗竭
- 自责 / 羞耻
- 愤怒 / 想反击
- 焦虑 / 反复想
- 关系不安
- 拒绝建议 / 只想说
- 求助 / 要办法
- 沉默 / 不想说
- 好事 / 开心
- 告别 / 丧失
- 迷茫 / 没方向
- 边界 / 依赖
- 高风险

不同特征可以增减，但不要按“夏目专区”“蔡康永专区”分。

### 第六步：蒸馏成 AI 能说的话

固定做六件事：

1. **保留动作**：这句话在做什么（接住、给选择、设边界）。
2. **删掉背景**：咨询室、剧情、人物关系。
3. **去身份**：不假装是咨询师、夏目、蔡康永。
4. **去恋爱化**：删掉告白、永远、唯一。
5. **缩短**：1–2 句，通常 30 字以内。
6. **配反例**：每条写“不要说什么”。

输出格式：

```text
用户：“……”
- A：“……”
- B：“……”
- 不要：“……”
- 来源：……
```

### 第七步：小规模验证

- 先选 12–16 条，不要 42 条全塞。
- 覆盖 7 个高频场景：低落、自责、愤怒、关系不安、拒绝、沉默、高风险。
- 用 30 条特殊场景跑一遍。
- 看它是在“接住”，还是在“背词库”。

### 第八步：出验收页

每收完一个特征，先给用户看一页验收，不直接进下一个。

验收页固定包含：

1. 总量：原话多少条、蒸馏多少条、几个场景。
2. 全量词库表：用户说 / A / B / 不要 / 来源。
3. 来源分布：真人、影视、动漫、书摘、网站各多少。
4. 质量分级：A/B/C 各多少。
5. 这版刻意没学什么。
6. 文件链接。
7. 一句话：这版哪里还需要改。

用户确认后，再开下一个特征。

## 3. 网站 / 社区采样清单

### 3.1 心理咨询 / 科普

- 简单心理
- 壹心理
- 渡过
- KnowYourself
- 暂停实验室

能补：真实咨询故事、来访者原话、专业回应。

### 3.2 媒体访谈

- 澎湃新闻
- 人物
- 新周刊
- 南方人物周刊
- 看理想
- 一席

能补：真人说话节奏、分寸、不防御。

### 3.3 影视 / 动漫

- 豆瓣（影评、台词摘录）
- 萌娘百科
- Bangumi
- 1905 电影网
- 各自动漫台词站

能补：日常对白、人物感、场景。

### 3.4 书籍

- 豆瓣读书（原文摘录）
- 微信读书
- 得到

能补：长期智慧、完整上下文。

### 3.5 社区

- 豆瓣小组
- 知乎
- 小红书
- 微博
- B站

能补：真实用户故事、原话、被温柔对待的瞬间。

注意：社区内容情绪浓度高、样本偏差大，必须追溯原出处。

### 3.6 学术 / 播客

- Nature npj Digital Medicine
- APA
- PubMed
- 中国知网
- 小宇宙
- 苹果播客

能补：方法依据、边界、伦理。

## 4. 网站素材可靠性分级

| 级别 | 是什么 | 怎么用 |
|---|---|---|
| S | 原始访谈、论文、官方稿 | 可直接引用 |
| A | 有署名、有场景的二手整理 | 可参考，最好回到原文 |
| B | 无署名语录合集、营销号 | 只用来发现线索，必须追溯原出处 |
| C | AI 生成、无法追溯 | 不收 |

一条素材至少要能回答：

- 谁说的？
- 在什么场景说的？
- 原始链接在哪里？
- 是原话，还是转述/翻译？

回答不了，不进词库。

---

## 5. 常见坑

### 网站类

1. 语录合集把不同人的话拼在一起。
2. 断章取义，删掉上下文。
3. 翻译失真，尤其是日文、韩文。
4. 营销号为了传播，把话改得更“金句”。
5. 平台算法偏好极端表达，不代表日常。

### 特征类

1. 只收句子，不收场景。
2. 把角色台词直接当 AI 台词。
3. 把咨询师话术直接搬。
4. 只收正面，不收边界和反例。
5. 一开始就收 100 条，不分层。
6. 把“温柔”收成“讨好”，把“直接”收成“刻薄”。
