# 心晴 Demo 演示流程

建议时长：4 分钟。访问地址：<http://127.0.0.1:5174/>。

## 演示前检查

- 保持现有前后端运行，不重复启动，不在演示前临时重启或换配置。
- 打开首页，并提前确认 `/api/auth/health` 正常。健康检查成功不等于模型调用成功，应提前完成一条真实聊天。
- 使用合成示例，不输入真实个人隐私。保留同一浏览器和 `127.0.0.1:5174` 来源，否则无法看到同一份本机历史。
- 演示依赖网络。情景通用接口现有限流为同一来源 10 分钟 60 次，辅助回应通常包含生成和核验两次调用；避免连续快速重复点击。

## 现场顺序

| 时间 | 操作 | 讲解重点 |
| --- | --- | --- |
| 0:00–0:25 | 打开首页，展示心情记录与陪伴者形象 | 心晴同时提供日常交流和沟通练习；本次重点展示 AI 核心流程 |
| 0:25–1:20 | 底部 AI → 历史会话 → 新建对话；完成下方三句示例 | 真实模型接话，近期上下文随当前会话传递 |
| 1:20–1:50 | 打开情景聊天 → 家庭 → 催婚 → 妈妈催婚 → 真实 → 开始演练 | 用户演自己，AI 演妈妈；对方先开场 |
| 1:50–2:35 | 发送两句自己的回应 | 人物可以坚持或缓和，不能替用户回答或自动完成目标 |
| 2:35–3:20 | 输入原意，点辅助回应 → 换一句 → 修改 → 主动发送 | 建议只是草稿，未发送不进入正式记录 |
| 3:20–4:00 | 结束演练 → 查看复盘 → 完成 → 展示最近练过 → 刷新后重新进入 | 复盘引用用户实际说过的话；记录保存在本机 |

## 可直接使用的演示输入

日常陪伴：

1. “今天散步看到一只橘猫，我给它起名叫南瓜，只想分享一下。”
2. “它钻到长椅底下，我没再靠近，让它自己待着。”
3. “你还记得我起的名字和它的颜色吗？”

情景回应：

1. “妈，我知道你担心我，但我现在不准备为了赶时间结婚。”
2. “我愿意听你的担心，但不会现在承诺结婚日期。”

辅助回应前先输入原意：“我希望按自己的节奏决定，不承诺结婚日期。”生成后保留立场，自行修改一处，再点“发送我的回应”。不要把建议草稿与正式台词混为一谈。

## 现场说明与异常处理

- 模型台词会变化，不承诺逐字复现。若出现未提供的地点或亲属细节，指出它是模型补写并立即纠正，不作为真实用户背景展示。
- 请求失败时展示真实错误，保留输入并等待网络恢复；不要用预录或模拟回复冒充实时回复。已有截图只能说明此前操作，不能代替现场联网状态。
- 若复盘出现“模型复盘暂时不可用”，说明当前展示的是从实发记录选取的本地兜底，不宣称模型复盘成功。
- “最近练过”的条目可用于再次练习；当前不把它讲解成完整历史逐条回放功能。
- 首页部分文字仍有强陪伴口吻；产品不承诺永久可用，不提供心理诊断或治疗。
- 完成当前演示即可，不展示尚未接入的语料检索、长期记忆或跨设备同步。

## 启动说明

当前服务已经运行，直接访问上述地址。仅在确认端口空闲、原服务已受控退出并获负责人批准后，使用原配置启动：

```powershell
Set-Location -LiteralPath 'C:\Users\汪晨\Desktop\心晴'
node --experimental-sqlite account-service/server.mjs
```

另开终端启动前端：

```powershell
Set-Location -LiteralPath 'C:\Users\汪晨\Desktop\心晴'
npm run dev
```

使用当前已有依赖和原运行环境，不修改 `.env`。`npm run build` 用于构建验证；`npm run preview` 不能直接替代现有带 `/api` 代理的开发入口。
