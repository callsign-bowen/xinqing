# 心晴陪伴舱整合 Demo

日期：2026-11-17。访问地址：http://127.0.0.1:5174/

## 本次实现

首页、情绪、AI、我的四个入口已整合到同一幅舱室全景。点击设备打开原有功能面板，关闭后返回舱室。底部四页导航不再显示。

| 舱内设备 | 对应功能 | 实现方式 |
| --- | --- | --- |
| 中央日志终端 | 心情选择、文字与图片记录、日记本、今日鼓励 | 复用原首页 DOM、事件和存储 |
| Nuo 陪伴基座 | 日常 AI 对话、新建对话、历史会话、输入及附件入口、求助 | 复用现有日常聊天链路 |
| 左侧情绪看板 | 情绪日历、趋势、心情快报 | 复用原情绪报告，打开面板后通知图表重新布局 |
| 后方收纳区 | 个人报告、陪伴者、账号与设置 | 复用原“我的”页 |
| 星空舷窗 | 氛围背景 | 不添加主要功能或点击入口 |

背景直接复用用户提供的图片，未修改图片内容，保留原图水印。背景中的图表、人物和书本是图像；实际数据和可操作控件在设备打开后的面板内。本版没有增加实时 3D、人物动画或新的模型能力。

手机端采用可左右滚动的全景，提供左右按钮和右上角“舱内导览”。桌面端设备标签均可见。面板具备返回、Escape 关闭、键盘焦点循环、返回触发入口和减少动画偏好支持。图片加载失败时仍可通过导览使用四项功能。

情景练习本轮不挂载入口。情景源代码、测试和历史存储均保留，未迁移或清理记录。
