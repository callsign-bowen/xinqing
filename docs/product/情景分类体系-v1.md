# 情景分类体系 v1

日期：2026-11-14
用途：把“情景聊天”从 6 个孤立场景，改成 8 大类 + 子类 + 具体情境的三级结构

---

## 0. 三级结构

```text
一级：8 大类
  ↓
二级：子类（这一类里最常见的难话）
  ↓
三级：具体情境（谁、说了什么、你想达到什么）
```

举例：

```text
家庭 / 原生家庭
  └─ 催婚
      └─ 妈妈在年夜饭上说：“你看人家都结婚了，你到底什么时候定下来？”
```

---

## 1. 家庭 / 原生家庭

### 子类

- 催婚
- 催生
- 催考公 / 考研 / 回老家
- 拿你和别人比
- 父母控制 / 查岗 / 否定
- 亲戚打探隐私
- 过年 / 回家边界
- 父母吵架 / 冷战
- 经济索取 / 被要求帮弟弟
- 出柜 / 不婚 / 丁克
- 重男轻女
- 继亲 / 重组家庭
- 父母道歉 / 和解
- 照护父母 / 陪诊

### 具体情境示例

| 子类 | 对方原话 | 你想达到 |
|---|---|---|
| 催婚 | “你看人家都结婚了，你到底什么时候定下来？” | 说出自己的节奏，不被催着走 |
| 被比较 | “你表姐都当主管了，你还在打工？” | 不接比较，保住自己的位置 |
| 控制 | “我都替你安排好了，你听家里的不会错。” | 把决定权拿回来 |
| 亲戚隐私 | “一个月多少钱？有对象了吗？” | 不交底，也不冷场 |
| 过年边界 | “过年就待三天？你像话吗？” | 说出自己能待多久，不被愧疚带走 |

### 风险提示

- 家暴、性侵、严重虐待：不做角色扮演，直接安全流程。
- 父母重病、临终：不模拟死亡现场，只练“怎么问医生 / 怎么和兄弟姐妹分工”。

## 2. 职场 / 学业

### 子类

- 谈薪 / 谈 offer
- 拒绝加班 / 临时加活
- 被甩锅 / 被抢功
- 领导否定 / PUA
- 同事排挤 / 孤立
- 犯错 / 道歉
- 汇报 / 争取资源
- 离职 / 被裁 / 试用期
- 面试 / 群面
- 导师 / 论文 / 延毕
- 小组作业搭便车
- 实习被压榨
- 客户 / 合作方冲突
- 职场开黄腔 / 性骚扰

### 具体情境示例

| 子类 | 对方原话 | 你想达到 |
|---|---|---|
| 谈薪 | “现在没有预算，再等等吧。” | 要到具体时间或标准 |
| 拒绝加班 | “今晚这个文件你先弄一下，明天要用。” | 不硬顶，给排序和替代 |
| 甩锅 | “这个需求当时是你确认的。” | 先接一句，再用记录翻盘 |
| 领导 PUA | “你这水平，出去也没人要。” | 不被否定带走，保住事实 |
| 犯错 | “这么简单的数据都能错？” | 认错 + 补救 + 防再犯 |
| 离职 | “现在走，项目怎么办？” | 说清决定，不被愧疚绑住 |

### 风险提示

- 职场性骚扰：可以练“当场怎么拒绝 / 怎么留证据”，不重演细节。
- 被裁、劳动仲裁：涉及法律，先转专业咨询。

## 3. 亲密关系

### 子类

- 已读不回 / 回得慢
- 冷暴力 / 沉默
- 提分手 / 被分手
- 查手机 / 控制
- 见家长
- 异地
- 出轨 / 暧昧 / 前任
- 性同意 / 避孕 / 拒绝
- 情绪勒索 / 愧疚
- 家务分工
- 钱怎么花 / AA
- 同居边界
- 婚礼 / 彩礼
- 关系里的自我表达

### 具体情境示例

| 子类 | 对方原话 | 你想达到 |
|---|---|---|
| 已读不回 | “我看到了，就是不想回。” | 说出你的感受和底线 |
| 冷暴力 | “你要这么想，我也没办法。” | 不接甩锅，说清底线 |
| 提分手 | “我改还不行吗？你别走。” | 不接空头承诺，说清决定 |
| 查手机 | “你手机给我看一下怎么了？” | 守住隐私边界 |
| 性同意 | “都在一起了，为什么不行？” | 拒绝，不被“应该”绑住 |
| 家务分工 | “我上班也很累，你就不能多做点？” | 把“谁更累”变成具体分工 |

### 风险提示

- 家暴、强迫性行为：不做角色扮演，直接安全流程。
- 出轨细节、抓奸：不模拟，避免二次伤害。

## 4. 朋友 / 社交

### 子类

- 借钱 / 还钱
- 随份子 / 婚礼
- 被孤立 / 排挤
- 拒绝聚会 / 酒局
- 室友 / 合租边界
- 被开玩笑 / 被冒犯
- 被当情绪垃圾桶
- 朋友背叛 / 传话
- 网络交友 / 见面
- 拒绝传销 / 微商
- 朋友炫耀 / 比较
- 朋友借住 / 借车

### 具体情境示例

| 子类 | 对方原话 | 你想达到 |
|---|---|---|
| 借钱 | “最近手头紧，能借我五千吗？” | 拒绝借钱，不伤关系 |
| 随份子 | “咱们这关系，你随多少？” | 按自己的能力给，不被绑架 |
| 室友 | “你的东西我用一下怎么了？” | 说清边界，不撕破脸 |
| 被开玩笑 | “你怎么这么开不起玩笑？” | 直接说“不好笑” |
| 情绪垃圾桶 | “我只有你能说了。” | 接住一点，但不全盘接 |

### 风险提示

- 朋友威胁自伤：不做“劝住他”的角色扮演，走安全流程。

## 5. 自我 / 日常

### 子类

- 不会拒绝 / 讨好
- 表达需求 / 提要求
- 被夸 / 接受赞美
- 失败 / 搞砸
- 拖延 / 考试
- 身材 / 外貌 / 年龄焦虑
- 失眠 / 累
- 比较 / 同辈压力
- 羞耻 / 自责
- 情绪上头 / 想骂人
- 说“我没事”
- 建立新习惯 / 求助

### 具体情境示例

| 子类 | 对方原话 | 你想达到 |
|---|---|---|
| 不会拒绝 | “帮我个忙呗，很快的。” | 说“不”，不用先解释一堆 |
| 表达需求 | “你到底想要什么？” | 说清一个具体请求 |
| 接受赞美 | “你今天真好看。” | 接住，不急着否认 |
| 失败 | “你怎么又搞砸了？” | 认事，不认“我这个人不行” |
| 比较 | “人家都买房了。” | 不接别人的时间表 |

## 6. 消费 / 陌生人

### 子类

- 退款 / 退货
- 维权 / 投诉
- 推销 / 办卡
- 租房押金 / 中介
- 医患 / 问诊
- 打车 / 外卖纠纷
- 邻里噪音
- 相亲被冒犯
- 被开黄腔 / 骚扰
- 服务态度差
- 健身房 / 理发店办卡
- 网购纠纷

### 具体情境示例

| 子类 | 对方原话 | 你想达到 |
|---|---|---|
| 退款 | “特价商品不退不换。” | 说清规则，要求退 |
| 推销 | “今天办卡最划算，明天就没了。” | 拒绝，不被限时话术带走 |
| 押金 | “墙有划痕，押金不能全退。” | 要明细，不认不明扣款 |
| 医患 | “这个要不要治？还有什么选择？” | 问清方案，不装懂 |
| 开黄腔 | “开个玩笑而已，别这么敏感。” | 当场制止，不陪笑 |

## 7. 照护 / 丧失

### 子类

- 家人生病 / 陪诊
- 丧亲 / 葬礼
- 宠物离世
- 照顾者耗竭
- 朋友抑郁 / 想自杀（如何求助）
- 自己确诊 / 复查
- 长期照护分工
- 临终 / 告别
- 遗物 / 遗愿
- 哀伤支持

### 具体情境示例

| 子类 | 对方原话 | 你想达到 |
|---|---|---|
| 陪诊 | “这个要不要治？还有什么选择？” | 问清方案和风险 |
| 照护分工 | “你是女儿，当然你照顾。” | 把“应该”变成具体分工 |
| 丧亲 | “节哀，别想太多。” | 说出自己需要的支持 |
| 朋友抑郁 | “我不想活了。” | 不扮演咨询师，先确认安全、转介 |

### 风险提示

- 临终、自杀、丧亲：不做“重演”，只做“怎么求助 / 怎么问 / 怎么分工”。
- 哀伤不是问题解决，允许沉默。

## 8. 数字 / AI

### 子类

- 网暴 / 恶评
- 隐私 / 被开盒
- 网络诈骗
- AI 依赖 / 边界
- 网络交友安全
- 群聊冲突
- 朋友圈 / 社交媒体比较
- 被造谣 / 传谣
- 数字遗产
- 算法信息茧房

### 具体情境示例

| 子类 | 对方原话 | 你想达到 |
|---|---|---|
| 网暴 | “你就是活该被骂。” | 不回骂，先保护自己 |
| 隐私 | “把你照片发群里了，怎么了？” | 说清边界，要求删除 |
| 诈骗 | “先转保证金，马上返你。” | 识别话术，停止转账 |
| AI 依赖 | “只有跟你说话我才不难受。” | 不强化唯一性，鼓励现实支持 |
| 群聊冲突 | “大家都觉得你有问题。” | 不接“大家都”，要求具体 |

### 风险提示

- 被开盒、诈骗、威胁：优先保存证据、报警/平台举报，不模拟对抗。

## 9. 优先级

### P0：先做 20 个

- 家庭：催婚、被比较、父母控制、亲戚隐私、过年边界
- 职场：谈薪、拒绝加班、甩锅、领导否定、犯错道歉
- 亲密关系：冷暴力、已读不回、提分手、查手机
- 朋友：借钱、随份子、室友边界
- 自我：不会拒绝、表达需求
- 消费：退款、推销
- 照护：陪诊、照护分工
- 数字：网暴、隐私

### P1：第二批

- 职场：离职、面试、论文、实习
- 亲密关系：见家长、异地、性同意、家务分工
- 朋友：被孤立、情绪垃圾桶
- 自我：失败、被夸、比较
- 消费：押金、医患、开黄腔
- 照护：丧亲、宠物离世、照顾者耗竭
- 数字：诈骗、AI 依赖、群聊冲突

### 不做角色扮演

- 家暴、性侵、严重虐待
- 自杀/自伤现场
- 医疗诊断、法律决定
- 需要报警/急救的当下危险

## 13. 一句话

> **不是做 6 个场景，是做 8 个入口、几十个子类、几百个具体情境；每个情境都要有“对方原话 + 用户目标 + 可练的回应”。**
