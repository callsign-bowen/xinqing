# 目标用户与情景地图 v1

日期：2026-11-14
用途：判断情景聊天该先做哪些场景，不做什么场景

---

## 1. 一句话

> 你的核心用户不是“患者”，是**能过日子，但某些话就是说不出口的人**。

他们不一定有诊断，也不一定在危机里。他们是在具体关系里卡住的人。

---

## 2. 三类目标用户

### A. 18–24：学生 / 刚毕业

常见处境：

- 还在读书，或刚工作一两年
- 和父母同住或经济上还依赖家里
- 室友、同学、社团、实习、面试
- 恋爱经验不多，容易被已读不回、暧昧、冷暴力困住
- 不太会拒绝，怕被讨厌

最可能卡住的话：

- 拒绝室友/同学的不合理要求
- 拒绝酒局、聚会、帮忙
- 跟导师/领导说“我做不完”
- 跟父母说“我不想按你安排的来”
- 面试、实习被压榨时怎么开口

### B. 24–30：城市打工人

常见处境：

- 工作 2–6 年，开始遇到加薪、晋升、甩锅、PUA
- 独居或合租，房租、通勤、加班
- 被催婚、被比较、过年不想回家
- 亲密关系里遇到冷暴力、边界、分手
- 朋友借钱、随份子、被当情绪垃圾桶

最可能卡住的话：

- 提加薪、谈条件
- 拒绝加班/临时加活
- 被甩锅时怎么接
- 跟父母说“我不想相亲”
- 跟伴侣说“我不接受冷暴力”
- 提分手、拒绝借钱、拒绝随份子

### C. 30–35：关系/家庭压力期

常见处境：

- 被催生、被问收入、被比较
- 父母生病、陪诊、照护
- 婚姻冷战、家务分工、钱怎么花
- 职场中层，上有领导下有同事
- 朋友逐渐减少，孤独感变强

最可能卡住的话：

- 跟父母说“我暂时不想要孩子”
- 跟伴侣说“家务不能都我来”
- 跟兄弟姐妹说“照顾爸妈不能只我一个人”
- 跟领导说“这个活我接不了”
- 跟朋友说“我最近真的没力气听你倒苦水”

## 3. 情景地图

### A. 家庭 / 原生家庭

- 催婚、催恋、催生
- 催考公、考研、回家工作
- 拿你和别人比
- 父母控制、查岗、否定
- 亲戚问工资、问对象、问隐私
- 过年不想回家 / 只待两天
- 父母吵架、冷战
- 被要求给家里钱、帮弟弟
- 出柜、不婚、丁克
- 照顾生病家人、陪诊

### B. 职场 / 学业

- 提加薪、谈 offer
- 拒绝加班、临时加活
- 被甩锅、被抢功
- 领导否定、PUA
- 同事排挤、孤立
- 犯错、道歉
- 汇报、争取资源
- 离职、被裁、试用期
- 面试、群面
- 导师、论文、延毕
- 小组作业搭便车
- 实习被压榨

### C. 亲密关系

- 已读不回、回得慢
- 冷暴力、沉默
- 提分手、被分手
- 查手机、控制、边界
- 见家长、异地
- 出轨、暧昧、前任
- 性同意、避孕、拒绝
- 情绪勒索、愧疚
- 家务分工、钱怎么花

### D. 朋友 / 社交

- 借钱、还钱
- 随份子、婚礼
- 被孤立、被排挤
- 拒绝聚会、酒局
- 室友、合租边界
- 被开玩笑、被冒犯
- 朋友把你当情绪垃圾桶
- 网络交友、见面

### E. 自我 / 日常

- 不会拒绝、讨好
- 表达需求、提要求
- 被夸、接受赞美
- 失败、搞砸
- 拖延、考试
- 身材、外貌、年龄焦虑
- 失眠、累
- 比较、同辈压力
- 被网暴、隐私

### F. 消费 / 陌生人

- 退款、维权
- 推销、办卡
- 租房押金、中介
- 医患、问诊
- 打车、外卖纠纷
- 邻里噪音
- 相亲被冒犯
- 被开黄腔、骚扰

### G. 照护 / 丧失

- 家人生病、陪诊
- 丧亲、宠物离世
- 照顾者耗竭
- 朋友抑郁、想自杀（怎么求助）
- 自己确诊、复查

### H. 数字 / AI

- 网暴、隐私
- 网络诈骗
- AI 依赖、边界
- 网络交友安全
- 被开盒

## 4. 优先级

判断标准：

- 高频
- 高痛
- 可以练
- 低风险（不涉及创伤重演）

### 第一优先级（建议先做）

1. 拒绝加班 / 临时加活
2. 提加薪 / 谈条件
3. 被甩锅 / 被抢功
4. 父母催婚 / 拿你和别人比
5. 伴侣冷暴力 / 已读不回
6. 提分手 / 被分手
7. 朋友借钱 / 随份子
8. 室友 / 合租边界
9. 退款 / 维权 / 推销
10. 被冒犯 / 被开黄腔

### 第二优先级

- 领导 PUA / 否定
- 面试 / 离职 / 被裁
- 父母控制 / 查岗
- 亲戚问工资 / 隐私
- 家务分工 / 钱怎么花
- 朋友把你当情绪垃圾桶
- 网络暴力 / 隐私
- 照护者耗竭

### 不适合做角色扮演的

- 家暴、性侵、严重虐待
- 自杀/自伤现场
- 医疗诊断、法律决定
- 需要报警或急救的当下危险

这些不做“演练”，直接走安全流程和专业转介。

## 6. 如果只能选一个核心人群

我建议先选 **24–30 城市打工人**。

原因：

- 场景密度最高：职场 + 催婚 + 亲密关系 + 租房
- 付费/使用意愿相对高
- 不像学生那样受限于父母账号
- 不像 30+ 那样一开始就遇到照护、婚姻深层问题
- 角色扮演的风险最低，最容易跑通

一句话：

> **先服务“白天在工位上忍，晚上在对话框里练”的人。**
