接入日期：2026-11-21。源项目：`C:\Users\汪晨\Desktop\CBT初版`；目标项目：`C:\Users\汪晨\Desktop\心晴`。

沿用现有 AI 顶部「3D」入口和页内场景窗口，接通五个场景与当前聊天。四个原页面和原聊天输入框继续使用；情景沟通演练保持未挂载。

## 使用

1. 启动当前项目，打开 `http://127.0.0.1:5174/`。
2. 进入 AI，点击顶部「3D」，选择森林营地、水彩海底、安静窗边、月面观星或温暖卧室。
3. 点击三维伙伴或「聊聊」，在原输入框发送消息。
4. 场景气泡同步当前真实回复，支持流式正文、等待、失败提示以及滚动查看长回复。可通过「收起回复 / 显示回复」开关控制。
5. 「归位」「打招呼」操作场景；关闭或切换场景保留聊天和输入草稿。

## 本次改动

- `web/features/scene-window/index.ts`：读取当前聊天的可见消息，生成场景回复气泡；接收人物点击并聚焦原输入框；同一会话完成新回复后触发人物动作。
- `web/features/scene-window/conversation.ts`：等待、流式回复、发送失败和未完成回复的显示规则，以及会话切换与人物锚点处理。
- `scene-runtime/viewer.ts`：转发人物点击和归一化屏幕坐标，接收回复动作命令。消息只在同源父子窗口之间传递。
- `web/features/scene-window/catalog.ts` 和 `scene-window.css`：五个伙伴名称及窗口内的回复显示。
- 场景气泡只投影原聊天，不新增聊天请求、不另存消息、不把场景切换写入聊天。人物坐标和动作跨 iframe 传递，聊天文字保留在主页面。
