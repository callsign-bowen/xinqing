## 整合结果

- 仅挂载「月面观星」：原营地、山地、岩石、设备、地球、8K 星空与带动画的宇航员。
- 月面底部提供「首页 / 情绪 / AI / 我的」。原页面节点、事件处理、浏览器存储键和 API 沿用当前心晴项目。
- 首页、情绪、我的显示为原有功能面板，关闭返回月面；AI 保留输入框、语音、图片、会话历史与完整对话记录，最新回复跟随宇航员的屏幕位置。
- 点击宇航员进入 AI；支持拖动、方向键、手机左右按钮、视角归位与挥手。
- 其他面板打开时暂停渲染，返回月面或 AI 时恢复；加载失败可重试，四个页面不依赖场景加载成功。

没有接入原项目的场景选择器、森林、海底、窗边、卧室、登录和云端同步。旧舱室代码保留以便回退，入口不再导入或启动该渲染器；未挂载的情景练习保持原状。
