# 心晴 · 完整产品 Demo

本仓库保存当前可运行的完整产品项目：前端、Node.js 聊天后端、五个 3D 场景及其模型贴图、词库与语料、测试和产品说明。使用自己的模型密钥即可在本机运行。上传版本沿用当前产品功能开关，情景沟通演练代码保留，入口暂不启用。

保留原来的 **首页 / 情绪 / AI / 我的** 四页样式和底部导航。3D 不作为应用外壳，仅通过 **AI 页顶部「3D」按钮**选择并显示在页内的小窗口里。菜单包含 `CBT初版` 的森林营地、水彩海底、安静窗边、月面观星、温暖卧室五个场景。

| 页面 | 功能 |
| --- | --- |
| 首页 | 情绪打卡、纸质日记本（照片/天气/草稿/翻页声）、每日鼓励、今日能量、危机入口 |
| 情绪 | 情绪报告：指标、日历、趋势、心情快报（Chart.js） |
| AI | 流式对话、图片、语音输入、最近对话侧栏、风险提示 |
| 3D 场景聊天 | 森林营地、水彩海底、安静窗边、月面观星、温暖卧室；人物互动和当前聊天同步 |
| 我的 | 个人报告（4 个引导问题 + 最近变化）、陪伴者形象、账号与昵称、帮助、关于、清除本机数据 |

四页使用原来的页面节点、主题、数据和 API。聊天记录与输入框保留在原位；场景只占 AI 顶部区域，支持拖动环视、归位、打招呼、切换和关闭。离开 AI 或切到后台时暂停场景，关闭或换场景时卸载旧窗口，未选择场景时不启动 3D。**没有登录页和云端同步**，数据只保存在本机。三维场景需要 WebGL2；加载失败可重试，不影响原有四页和聊天。

### 在 3D 场景里聊天

进入 **AI → 顶部「3D」→ 选择一个场景**。点场景里的伙伴或窗口上的「聊聊」，即可在原输入框继续这段对话。真实 AI 回复会同步显示在场景气泡中，支持流式正文、等待和发送失败状态；长回复可以滚动阅读，点「收起回复」可专心看场景。场景人物会在收到新回复后做出动作回应。

切换场景、关闭窗口或切换四个页面，不创建新的聊天，不清空输入草稿，也不改变原有图片、语音输入和历史会话功能。情景沟通演练继续保持未挂载状态。

### 对话演绎（木偶默剧）

每轮 AI 回复后，系统在后台把这段对话里讲到的人际冲突（例如和爸妈吵架）整理成一出木偶默剧：出场人物、每一拍的动作和表情、字幕卡台词。演绎**不会自动弹出**；这段对话有演绎时，AI 页顶部才出现「演绎」按钮，点开才播放，可以逐拍翻看、切换每一版、删除。

- 后端：`POST /api/theater/script`（`account-service/theater.mjs` 负责提示词与结果校验）。只演用户讲过的事；用户转述的原话标为原话，概括的标「大意」；不知道对方说了什么就让对方沉默。高风险对话不排演。
- 前端：`web/features/theater/`。剧本存在本机 `localStorage` 的 `nuo_theater`，每段对话最多保留 12 版。
- 3D 场景里看演绎：AI 页「3D」→「月面观星」，点场景里的电视，镜头会飞到电视正前方，在电视屏幕上播放这段对话的演绎；点「离开电视」（或 Esc、「归位」）回到原来的视角。电视是用 Blender 建的模（`tools/blender/signal_tv.py`），信号接收锅锁定地球信号后电视才有画面。
- 其他场景想加能播放演绎的物件：在 `scene-runtime/web/screenProps.ts` 登记一个 `ScreenProp`（点击范围、屏幕网格、机身朝向）即可，点击、镜头飞行和屏幕播放都是通用的。弹窗和电视共用同一个木偶舞台组件 `web/features/theater/stage.ts`。
- 月面宇航员的动作（`tools/blender/astronaut_actions.py` 在 Blender 里生成 18 段动作 → `public/models/lunar-astronaut-actions.glb`，预览视频 `tools/blender/astronaut_actions_preview.mp4`）：待机呼吸 + 每 10～20 秒随机小动作；你打字时歪头听、等回复时托腮想、回复出来时比划着说；不聊天时每 20～40 秒在营地附近飘到另一个点；点他就是“戳”——戳头盔捂头、戳身体缩一下、戳手击掌、飘着时戳会在空中转一圈、3 秒连戳 3 下假装生气；点月面上的空地，他会飘过去（地上出现蓝色光圈），到了转身面向你，之后聊天也待在那里，点椅子、灯、电视等物件不会触发。行为逻辑在 `scene-runtime/web/astronautBrain.ts`。表情：Blender 在脸上加了一层贴合面罩里脸部的薄贴片（`Astronaut_Face`，绑在头骨上，原五官烘焙图 `tools/blender/astronaut_face_original.png`），场景里用画布实时画五官（`scene-runtime/web/astronautFace.ts`）：16 种表情跟着动作切换，平时随机眨眼、眼珠小幅转动，说话时嘴巴一张一合。
- 人物素材：现在是分部件 SVG 占位木偶。正式素材放进 `public/theater/<角色>/`，在 `web/features/theater/cast.ts` 的 `PUPPET_ASSETS` 里登记即可替换。

## 下载与运行

推荐使用 Node.js 24、Git 和 Git LFS。开发及验证环境为 Node.js 24.19.0。

模型由 Git LFS 管理。请用 Git 克隆并拉取 LFS 资源，确保模型为完整文件；GitHub 的单文件预览可能只显示 LFS 指针。

```powershell
git lfs install
git clone https://github.com/callsign-bowen/xinqing.git
cd xinqing
git lfs pull
npm ci
Copy-Item account-service/.env.example account-service/.env
```

编辑 `account-service/.env`，填写自己的 `AI_API_KEY`。仓库只包含无密钥的配置示例；真实密钥、运行数据库和本机历史记录不加入版本管理。macOS / Linux 可将上述 `Copy-Item` 换成 `cp`。

先在第一个终端启动后端：

```powershell
npm run server
```

再在项目目录打开第二个终端，启动前端：

```powershell
npm run dev
```

打开 <http://127.0.0.1:5174/>。后端默认监听 `127.0.0.1:3001`，前端通过代理调用后端。首次会走一遍引导，可以点“跳过”。AI 聊天需要有效的模型密钥和网络连接；日记、打卡、主题及场景浏览可在模型服务未连接时使用。

森林原始模型约 153 MB，首次打开时加载较大。所有场景按需加载，主页面不会一次加载五个场景。

## 对话行为

- 默认 `CHAT_MODE=natural`：模型只输出正文，不输出 JSON；提示词带称呼和当前时间。
- `/api/chat` 支持 `stream: true`（SSE），前端逐字显示；旧后端会自动退回普通 JSON。
- 每轮只把**本段对话最近 12 条可见文字**随请求发给服务端（不含其他会话、个人资料和图片 Base64）；服务端优先用它，数据库只做记录和兜底。新建对话时快照里只有新问候，等于从零开始。
- “累、难过、焦虑”不会弹求助面板，只有明确的自伤表达才提示。
- 不替用户补身份、原因、期限，也不替第三方读心；信息不够时先问一句，不编场景。

## 数据

- 保存在浏览器 `localStorage`（`nuo_emotions`、`nuo_chat_sessions`、`nuo_personal_report` 等）。
- 端口是 **5174**，和原项目 5173 是不同来源，旧记录不会自动带过来。
- 图片以 Base64 存本地，长对话和大量照片会占用 localStorage。
